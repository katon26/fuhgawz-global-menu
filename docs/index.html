Your app menus, back in one bar.

FUHGAWZ Global Menu moves File, Edit, View, and Help out of every window and into a single native top bar, with a system menu, user switcher, recent items, and force quit on the same key. GTK 3, GTK 4, Qt, and dbusmenu apps, one place.

How menus reach the bar

  1. 01 GTK 3 apps gtk-modules=appmenu-gtk-module Classic D-Bus menu export, restored on modern distros where it is no longer the default.
  2. 02 GTK 4 apps org.gtk.Actions Modern headerbar-driven apps are read directly and grouped into the same menu.
  3. 03 Qt & others com.canonical.dbusmenu A session registrar lets compatible apps export menus without per-app configuration.

The extension probes every source and shows the first menu that answers. Apps with no exported menu fall back to the system menu, so the bar never goes empty.

Install in two steps

Clone the repository, run ./install.sh, then enable the extension. The script copies the modules, compiles the schema, and configures the GTK 3 and GTK 2 modules for menu export, so no distro packaging is required.
