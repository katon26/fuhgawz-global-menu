Core Engine gtk-modules=appmenu-gtk-module

Direct App Menu Integration

File, Edit, View, and Help from the focused application are extracted and rendered directly into GNOME's top panel. Hovering between menus triggers instant submenus with full keyboard accelerator support.

File Edit View Terminal Help
Live Activity MPRIS + Nautilus I/O

Dynamic Live Indicator

More than a static menubar. As your media player streams or Nautilus transfers files, the top panel integrates an interactive live indicator capsule with Cairo wave equalizers, progress scrubbing, and Libadwaita hover cards.

Media · Playing Nautilus · 84%
Modern Apps org.gtk.Actions

GTK 4 Action Grouping

Modern libadwaita apps (such as GNOME Text Editor and GNOME Builder) do not export classic menus by default. The extension inspects org.gtk.Actions from active headerbars and groups them logically so modern apps stay fully accessible.

Qt & Electron com.canonical.dbusmenu

Session-Wide Registrar

A background D-Bus registrar lets Qt 5/6, KDE, and open-source editor applications like VSCodium broadcast their menu structures automatically without per-application launcher overrides.

System Tools src/systemMenu.js

Integrated System Menu

User switcher, recent documents, force quit, and quick-settings hiders live on the exact same shortcut key as the app menu. Fast access when you need it, invisible when you do not.

Compatibility GNOME 45–50

Modern GNOME Shell

Maintained and verified across GNOME 45, 46, 47, 48, 49, and 50. Ships with a full libadwaita preferences dialog for menu placement, dynamic indicator tuning, and hotkey binding.

Engineered for solid compatibility across every major Linux distribution and custom desktop session. Installs purely in user space with no external package repositories, PPAs, or system tampering required.

How menus reach the bar

A resilient 3-layer pipeline guarantees your panel always has a menu ready.

01 Source

Application Layer

gtk-modules=appmenu-gtk-module

Classic GTK 3 and compatible applications export their native menu trees over D-Bus automatically.

02 Bridge

Resolution Engine

org.gtk.Actions & dbusmenu

When an app uses GTK 4 or Qt, the fallback engine queries action groups and session registrars to build menu structures dynamically.

03 Shell

GNOME Top Bar

Clutter + dynamic live indicator

Rendered natively inside GNOME Shell with hover submenus, live media capsules, and a system menu fallback if no app menu answers.

✓

The extension probes every source and renders the highest fidelity menu that answers. Apps with no exported menu fall back gracefully to the system menu, so the bar never goes empty.
