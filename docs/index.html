GNOME 45–50 · GPL-3.0 · Native D-Bus

Your app menus, back in one bar.

FUHGAWZ Global Menu brings application menubars directly into the GNOME Shell top bar. Powered by a 6-tier fallback engine, it extracts and renders menus across Wayland, GTK 4 / Libadwaita apps, GTK 3, Qt, and browser windows. Also include with system logo menu with user switcher, recent items, and force quit on the same key.

One bar. Every menu.

Engineered for pure speed, zero configuration, and consistent desktop ergonomics.

Core Engine gtk-modules=appmenu-gtk-module

Direct App Menu Integration

File, Edit, View, and Help from the focused application are extracted and rendered directly into GNOME's top panel. Hovering between menus triggers instant submenus with full keyboard accelerator support.

File Edit View Terminal Help
Modern Apps org.gtk.Actions

GTK 4 Action Grouping

Modern libadwaita apps (such as GNOME Text Editor and GNOME Builder) don't export classic menus by default. The extension inspects org.gtk.Actions from active headerbars and groups them logically so modern apps never feel missing.

Qt & Electron com.canonical.dbusmenu

Session-Wide Registrar

A background D-Bus registrar lets Qt 5/6, KDE, and open-source editor applications like VSCodium broadcast their menu structures automatically without per-application launcher overrides.

System Tools src/systemMenu.js

Integrated System Menu

User switcher, recent documents, force quit, and quick-settings hiders live on the exact same shortcut key as the app menu. Fast access when you need it, invisible when you don't.

Compatibility GNOME 45–50

Modern GNOME Shell

Maintained and verified across GNOME 45, 46, 47, 48, 49, and 50. Ships with a full libadwaita preferences dialog for menu placement, padding, and hotkey binding.

How menus reach the bar

A resilient 3-layer pipeline guarantees your panel always has a menu ready.

01 Source

Application Layer

gtk-modules=appmenu-gtk-module

Classic GTK 3 and compatible applications export their native menu trees over D-Bus automatically.

02 Bridge

Resolution Engine

org.gtk.Actions & dbusmenu

When an app uses GTK 4 or Qt, the fallback engine queries action groups and session registrars to build menu structures dynamically.

03 Shell

GNOME Top Bar

Clutter + systemMenu fallback

Rendered natively inside GNOME Shell with hover submenus, keyboard shortcuts, and a system menu fallback if no app menu answers.

✓

The extension probes every source and renders the highest fidelity menu that answers. Apps with no exported menu fall back gracefully to the system menu, so the bar never goes empty.

Install in two steps

Clone the repository, run ./install.sh, then enable the extension. The installer copies the modules, compiles the GSettings schema, and configures the GTK 3 and GTK 2 modules for menu export, with zero distro packaging required.
